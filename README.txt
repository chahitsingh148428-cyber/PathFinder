PathFinder + Zirius — GitHub Pages static website

Upload/replace index.html, style.css and app.js in your GitHub repository root, commit to main, then keep Settings > Pages set to main / (root).

Zirius is a local rule-based stream suggestion demo, not a live generative AI. Sign in stores a demo profile only in the current browser; it is not secure authentication and does not sync. Career and eligibility details are general guidance; verify current official rules before making decisions. A GitHub Pages URL can be public, but appearing in search results for the name PathFinder is not immediate or guaranteed. A custom domain is optional and typically costs money.
